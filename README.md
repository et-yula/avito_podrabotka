# avito_podrabotka
репо под курсовую работу по курсу "Машинное обучение" 


## Данные для курсовой работы

В проекте используется синтетический датасет платформы АВИТО ПОДРАБОТКА. Все записи сгенерированы для учебной задачи. Это не выгрузка Авито и не реальные показатели бизнеса. Исполнители, работодатели, адреса, контакты, налоговые и банковские идентификаторы вымышлены.

Период фактов: 01.04.2026–30.09.2026, шесть завершённых календарных месяцев. Срез: 01.10.2026 00:00:00, московское время (+03:00). Справочники содержат историю до апреля. Также включены заранее опубликованные смены на 1–7 октября и записи на них, созданные до среза. Их будущие результаты ещё неизвестны.

Исходный набор состоит из шести таблиц:

- `dm_gigs_performers.csv` — исполнители;
- `dm_gigs_shifts.csv` — смены;
- `dm_gigs_client_outlets.csv` — работодатели и рабочие точки;
- `dm_gigs_bookings.csv` — записи на смены;
- `dm_gigs_payments.csv` — попытки выплат исполнителям;
- `dm_gigs_events.csv` — пользовательские и серверные события.

Исходные CSV не включены в Git-репозиторий из-за их размера.

### Подготовка данных

1. Скачайте архив с исходным датасетом: https://disk.yandex.ru/d/vBYqQFGnoIH3QQ.
2. Распакуйте шесть CSV в папку `data/raw/`.
3. Установите зависимости из `requirements.txt`.
4. Запустите ноутбуки из папки `notebooks/` в указанном порядке.

Описание полей и метаданные расположены в `data/metadata/`.
